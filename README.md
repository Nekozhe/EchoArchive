# 回声档案（EchoArchive）

> 鸿蒙高级应用开发工程师认证 · 期末大作业（主题一：迷雾档案 · 校园线索推理与多结局探索）

一个运行在 HarmonyOS 上的**单机校园推理应用**。玩家受辅导员委托调查一起实验室原型机失窃案，在 3 个场景中探索取证、盘问 4 名关系人，把线索放入推理槽验证假设，最终指认嫌疑人并进入不同结局。项目为**独立完成**。

## 功能概览

| 模块 | 说明 |
| --- | --- |
| 委托与开场 | 案件简报、开新档 / 继续上局 |
| 场景探索 | 3 个可探索场景，热点取证，节点带前置条件 |
| 线索板 | 线索卡收集、详情查看、关键线索标记 |
| 盘问对话 | 对话树 + 出示线索解锁新分支 |
| 推理台 | 人物 / 时段 / 物证三槽位组合校验，错误可重试 |
| 结局系统 | 3 种条件触发的结局 + 推理复盘 |
| 存档 | 自动保存进度，退出应用进程后重新打开可恢复 |

## 运行方法

1. DevEco Studio 打开本目录（`File > Open`），等待 `Sync` 完成。
2. 启动模拟器：`Tools > Device Manager`，选择 API 26 模拟器并启动。
3. 选择 `entry` 模块，点击 `Run 'entry'`。
4. 应用启动后进入委托页。
